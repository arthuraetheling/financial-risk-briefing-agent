The hashes are of the files with LF line endings, which is how Git stores them. A Windows
checkout with core.autocrlf=true writes CRLF endings, which changes the hashes.

The two lists are identical. To check a copy of this project:
    certutil -hashfile risk_tools.py SHA256    (Windows)
    sha256sum briefing_agent.py risk_tools.py run_demo.py data/*.csv    (macOS or Linux)
